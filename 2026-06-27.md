# Diario de Trabajo — 27 de junio de 2026

## Actividad: Players de cartelería Admira.tv para Windows y Linux (fase 1, Electron)

Continuación de la línea de players de la plataforma de digital signage **admira.tv**: tras el
player nativo de macOS (e iOS), hoy se han creado y publicado los de **Windows** y **Linux**.

### Decisiones
- **Stack:** un único shell **Electron** (kiosko WebView sobre `www.admira.tv`) cubre Windows y
  Linux en una sola base de código. Acordado con Carlos hacer esta fase 1 con Electron, verificarla,
  y en una **fase 2** rehacer todo en nativo por plataforma + añadir Android nativo.
- **Repos:** monorepo en `csilvasantin/admira-player` (subárbol `electron/`, junto al macOS nativo).
- **Builds:** GitHub Actions CI escrito; los binarios de esta primera entrega se compilaron a mano en
  el Mac (electron-builder trae su propio wine) y se subieron a R2.

### Comportamiento (paridad con el player macOS)
Kiosko a pantalla completa, anti-reposo, auto-reconexión con backoff 2→30s, watchdog de render
(ping 60s/3-miss + reload ante crash), kill-switch **Escape**, y config de flota `screen`/`circuit`
por CLI / env / `config.json`. UA propio (`AdmiraWindowsPlayer`/`AdmiraLinuxPlayer` + `AdmiraKiosk`)
que dispara la redirección del sitio a `canal.html?embed=mupi`. Verificado en runtime en el Mac.

### Artefactos publicados (R2 `admira-tv-player`, v.26.06.27.r1)
- Windows: `.exe` (instalador NSIS, 78 MB) + `.zip` portable (106 MB).
- Linux: `.AppImage` (103 MB). El `.deb` no compila bien desde macOS (fpm) → vendrá del CI.

### Repositorios afectados
- `csilvasantin/admira-player`: subárbol `electron/` + tag `v.26.06.27.r1` (CI en local, pendiente de
  push por scope `workflow` del token gh).
- `csilvasantin/admira-tv`: página `/player/` con Windows y Linux **Disponibles** (enlaces a R2) y
  regex de detección de UA del `index.html` ampliado.
