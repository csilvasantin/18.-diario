Skill Diario IA

Skill compartible para que cualquier miembro de AdmiraNeXT pueda pedir al final del dia: "cierra mi diario" y obtener una entrada en el mismo formato factual del Diario.

Descargar ZIP Ver SKILL.md Ver ejemplo

Version inicial publicada para equipo. Contiene SKILL.md y example-entry.md.

Instalacion

1. Descargar

Baja diario-ia.zip y descomprimelo.

2. Copiar

Coloca la carpeta diario-ia dentro de .codex/skills/.

3. Usar

Abre Codex y pide: usa diario-ia para cerrar mi dia.

Windows:
C:\Users\TU_USUARIO\.codex\skills\diario-ia\

macOS / Linux:
~/.codex/skills/diario-ia/

Que produce

  • Una entrada Markdown lista para pegar en el diario.
  • Secciones: Que se hizo, Que se valido, Avances, Decisiones tomadas y Siguientes pasos.
  • Solo hechos verificables: conversaciones, commits, diffs, documentos, PRs, tareas o notas de la persona.
  • Opcionalmente, un bloque JS compatible con el array entries de la web del Diario.
