1. **Todas las API keys server-side** (en el worker), no en localStorage del browser. Modal `⚙ KEYS` simplificado a solo el Voice ID opcional.

3. **Bridge AdmiraXP**: el game se identifica a si mismo como Xtore (heartbeat con `role:'xtore-game'`) y muestra el feed en overlay flotante DENTRO del game. No se montó en una pantalla aparte porque era mas inmediato.

5. **`127.0.0.1` en lugar de `localhost`** para evitar HSTS upgrade desde github.io.
6. **`Access-Control-Allow-Private-Network: true`** en CORS de suno-local para satisfacer Chrome PNA.
