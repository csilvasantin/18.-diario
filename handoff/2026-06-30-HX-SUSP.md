## 5. Decisiones de la sesión

- **Patrón de 2 commits**: feature primero → capturar `git rev-parse --short HEAD` → Edit del CHANGELOG sustituyendo `(PENDING)` por el enlace githack del hash → commit doc. (El enlace githack apunta al commit del **feature**, no al del doc.)
- **Sustituir PENDING con el tool Edit, NO con sed** (sed daba exit 0 sin reemplazar).
- **Sanity de llaves** con node (`{` vs `}`) antes de cada deploy + `preview_console_logs level=error` tras recargar.
- **Limpieza obligatoria** del backend (POST vacío a `xtanco-bcn-gracia` y `saves-xtanco-bcn-gracia`) y de `localStorage` (`decor:xtanco-bcn-gracia`) tras probar features que escriben datos.
- **preserveDrawingBuffer:true** activado en el WebGLRenderer (necesario para capturar miniaturas .13 y foto .15).
- `git fetch` da a veces `SSL_ERROR_SYSCALL` transitorio; el push suele entrar igual — reintentar/seguir.
