Se monto bridge Pixer → AdmiraXP en r29-r33: KV namespace `SIGNAGE_KV` en el worker, endpoints `/signage/{push,feed,asset,ack,heartbeat,screens,clear}`, panel de progreso con preview thumb en Pixer, `signage.html` standalone Matrix-style en URL estable, badge `XTORE 🟢/🟡/🔴` en topnav que muestra version del game.

   c. `curl /lyria3/generate` con lyrics devolvio MP3 con `[0.0:5.2] We code in the night` cantado por voz real, header ID3 valido.

   h. `curl /yt/import` con video corto bajo MP3 384KB en ~3s, file devolvio `Audio file with ID3 version 2.4.0`.

3. Avances
   a. Worker `pixer-eleven` pasa de tener 5 endpoints a tener 22 (incluye llm/lyrics, lyria/generate, lyria3/generate, imagen/generate, veo/* asincrono con polling, signage/* completo).
   b. Pixer ahora tiene los 4 motores (Audio, Musica, Imagenes, Video) conectados a APIs reales en lo que es posible sin captcha.
   c. Bridge Pixer ⇄ AdmiraXP funciona end-to-end: `▶ REPRODUCIENDO en pantalla` con `screen-id` real cuando el game o `signage.html` muestra el item.
   d. Badge `XTORE v26.03.05.4 · LIVE` en Pixer detecta automaticamente el game corriendo y su version desde `window.XTANCO_APP`.
   e. Generador de letras + Lyria 3 = pipeline completo de cancion (letra IA + voz cantando) en menos de 30s.

4. Problemas encontrados
   a. ElevenLabs Free Tier marcado `detected_unusual_activity` por su sistema antifraude desde la primera llamada — bloqueado, requiere upgrade a Starter $5/mes o contactar soporte.
   b. Suno bloqueado por Cloudflare Turnstile en `/api/generate/v2-web/` — el JWT de `__session` caduca cada ~15 min y el captcha es por peticion, requiere integrar 2Captcha.
   c. Gemini API en Free Tier devolvio `limit:0` en Lyria 3 — el usuario activo billing del proyecto GCP y se desbloqueo.
   d. xAI renombro modelos: `grok-2-image` no existe, hay que usar `grok-imagine-image` y `grok-imagine-image-pro`.
   e. `IMPORTAR` desde el browser dio `TypeError: Failed to fetch` por dos razones combinadas: (1) HSTS upgrade de github.io que convertia `http://localhost` en `https://localhost` y (2) Chrome Private Network Access que bloquea `https publico → IP privada` sin header `Access-Control-Allow-Private-Network`.

5. Decisiones tomadas
   a. Mover todas las API keys server-side al worker `pixer-eleven` y borrar los inputs de keys del modal de Pixer (excepto el Voice ID opcional de ElevenLabs).
   b. Crear KV namespace `SIGNAGE_KV` con TTL 7 dias por item para no acumular basura.
   c. Inyectar el snippet de heartbeat + feed render en el `game.html` del AdmiraXP (vs crear una pantalla aparte) para que el game se reconozca a si mismo como Xtore sin necesidad de abrir signage.html en otra ventana.
   d. Usar `127.0.0.1` en lugar de `localhost` en los fetches para evitar HSTS upgrade.
   e. Postergar Suno hasta proxima sesion (requiere $3 setup 2Captcha + cookie refresh dance) y centrarse en alternativas oficiales (Lyria 2/3).
   f. Usar `signage.html` como pantalla standalone (URL estable fuera de carpetas versionadas) para casos en que no se quiera meter el snippet en una app concreta.

6. Siguientes pasos
   a. Verificar IMPORTAR end-to-end con `Cmd+Shift+R` tras el fix de PNA. Si Chrome sigue bloqueando: tocar `chrome://flags/#block-insecure-private-network-requests` o cambiar de browser.
   b. Re-extraer cookie de Suno + integrar 2Captcha si se quiere desbloquear ese motor de musica.
   c. ElevenLabs: decidir entre upgrade a Starter $5/mes o contactar soporte para desbloquear Free Tier.
   d. Anadir mute total en game AdmiraXP (peticion del usuario que se quedo a medias por pivot a fix de badge XTORE).
   e. Mejora futura: integrar el feed de Pixer en una pantalla dentro del game (VAPES, VINOS) en vez de overlay flotante — requiere meter en canvas.
